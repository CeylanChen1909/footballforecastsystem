# 数据源使用边界

当前生产比赛主源为 BBC scores/fixtures 页面，其他来源只作为明确配置的赛前详情或离线历史增强，不得直接写入 `crawler_matches`。

每个来源必须满足：

- 记录来源标识、原始链接、抓取时间和字段更新时间；
- 遵守目标站点 robots、服务条款和访问频率限制；
- 解析器通过页面签名和字段完整性 canary 后才能把响应标记为成功；
- 空响应、页面结构变化、请求失败和额度受限分别记录，不得互相伪装；
- 队徽、头像、文章摘要只保存必要索引或缓存，并保留原站署名/跳转链接；
- 来源切换必须先运行 schema-preflight、重复身份审计和回放测试。

如果无法确认来源授权或页面结构稳定性，应关闭该来源，而不是把不确定数据展示为事实。
